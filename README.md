Emergency Requests Analyzer

Description

A Python program that analyzes emergency maintenance requests over a seven-day period.

The project demonstrates basic data analysis using Python lists, loops, conditional statements, and mathematical calculations.

Features

* Calculates the total number of requests.
* Calculates the average number of daily requests.
* Identifies the days with the highest and lowest number of requests.
* Counts days that meet the daily target of 12 requests.
* Compares weekday and weekend workloads.
* Identifies high-workload days with more than 15 requests.
* Calculates workload percentages and averages.
* Classifies the overall weekday workload as normal or critical.

Technologies

* Python 3
* No external libraries required.

How to Run

1. Install Python 3.
2. Download emergency_requests.py.
3. Open a terminal in the project folder.
4. Run the following command:
    python emergency_requests.py
